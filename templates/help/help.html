Начало работы

Регистрация учётной записи

Система доступна в браузере по адресу http://127.0.0.1:8000. При первом обращении без авторизации пользователь автоматически перенаправляется на страницу входа. Для создания новой учётной записи нажмите ссылку «Зарегистрироваться».

Введите логин, пароль и подтверждение пароля, затем нажмите «Зарегистрироваться». Система отобразит страницу ожидания активации.

Самостоятельный вход до активации администратором невозможен.

Вход и выход из системы

Вход

После активации учётной записи откройте http://127.0.0.1:8000. Введите логин и пароль и нажмите «Войти». При успешной авторизации система откроет главную страницу со списком заказов.

Выход

Нажмите кнопку «Выйти» в нижней части бокового меню. Система завершит сеанс и вернёт вас на страницу входа.

Интерфейс системы

Интерфейс состоит из двух частей: бокового меню навигации слева и основной рабочей области справа.

Боковое меню содержит ссылки на все разделы, сгруппированные по назначению: Заказы, Клиенты, Марки и модели, Услуги, Склад, Закупки. В нижней части меню расположены кнопки «Справка» и «Выйти», а также отображается имя текущего пользователя.

Работа с клиентами

Клиенты и автомобили

Список клиентов

Нажмите «Клиенты» в боковом меню. Таблица показывает ФИО, номер телефона и количество привязанных автомобилей. Для поиска введите ФИО или телефон в строку поиска.

Добавление клиента

Нажмите «Добавить клиента». Заполните ФИО, код страны и номер телефона, отметьте согласие на обработку персональных данных. Система проверяет уникальность телефона при сохранении.

Карточка клиента

Откройте карточку нажатием на имя клиента — здесь видны его контактные данные и список автомобилей. Для редактирования и удаления используйте соответствующие кнопки.

Добавление автомобиля

В карточке клиента нажмите «Добавить автомобиль». Выберите марку — список моделей обновится автоматически. Заполните государственный номер, VIN, цвет и год выпуска.

Система проверяет уникальность VIN и государственного номера. При дублировании форма не сохраняется.

Работа с заказ-нарядами

Создание заказ-наряда

На главной странице нажмите «Добавить заказ». Начните вводить ФИО или телефон клиента — система покажет подходящие варианты. Выберите клиента и его автомобиль из подгруженного списка, укажите текущий пробег и при необходимости комментарий.

После нажатия «Сохранить» заказ создаётся со статусом «Первичный осмотр».

Создать заказ задним числом невозможно — дата не должна быть в прошлом.

Карточка заказ-наряда

Добавление услуг

Нажмите «Добавить услугу» в карточке заказа. Откроется окно со списком услуг, сгруппированных по типам. Нажмите на услугу — она переместится в правую часть «Выбранные». Скорректируйте нормо-часы и коэффициент сложности — цена пересчитается автоматически. Нажмите «Добавить выбранные».

Добавление запасных частей

Нажмите «Добавить деталь». Введите наименование или артикул — система покажет варианты из каталога с остатком на складе. Выберите деталь и укажите количество. При наличии достаточного остатка деталь будет автоматически зарезервирована.

Назначение исполнителя

Рядом с нужной услугой нажмите кнопку назначения и выберите сотрудника из списка. Имя исполнителя и его коэффициент фиксируются в заказе.

Изменение статуса

Заказ последовательно проходит статусы: Первичный осмотр → Диагностика → В работе → Готов. Допускается возврат к предыдущему статусу. Управление осуществляется через блок «Изменить» в карточке заказа.

Завершение заказа

Завершение возможно только из статуса «Готов» при обязательно указанном способе оплаты. При завершении зарезервированные детали списываются со склада, данные фиксируются. Редактирование завершённого заказа невозможно.

Отмена заказа

Заказ можно отменить из любого активного статуса кнопкой «Отменить». Все зарезервированные детали автоматически возвращаются в свободный остаток.

Завершённые заказы удалить нельзя — это защита целостности истории.

Печать документов

В карточке заказа нажмите кнопку «Печать ▾» — раскроется выпадающее меню с тремя пунктами:

  • Для механика — технический бланк с перечнем работ и деталей без стоимости; доступен только для незавершённых заказов.
  • Лист отборки — список деталей для комплектации со склада; отображается только при наличии деталей в заказе.
  • Заказ-наряд клиенту — для активных заказов формирует предварительный документ, для статуса «Готов» или «Завершён» — финальный с итоговой стоимостью.

Справочники

Марки и модели автомобилей

Нажмите «Марки и модели» в боковом меню. Выберите строку в таблице — активируются кнопки «Подробнее», «Изменить» и «Удалить».

Для добавления марки нажмите «Добавить марку». Для просмотра и добавления моделей выберите марку и нажмите «Подробнее».

Удаление марки невозможно, если к ней привязаны автомобили клиентов.

Услуги

Нажмите «Услуги» в боковом меню. Каталог услуг организован по типам. Выберите тип и нажмите «Подробнее», чтобы просмотреть и добавить услуги данного типа. При добавлении услуги укажите название и базовое время в нормо-часах.

Базовое время — значение по умолчанию при добавлении услуги в заказ; его можно изменить непосредственно в заказе.

Склад и закупки

Работа со складом

Номенклатура деталей

Раздел «Номенклатура» содержит список всех деталей с артикулами и названиями. Для добавления нажмите «Добавить деталь» и укажите артикул, название и при необходимости бренд.

Остатки на складе

Страница «Остатки» показывает все позиции хранения: место хранения, общее количество, зарезервированный и доступный остаток, минимальный порог. При снижении остатка ниже минимума позиция выделяется в таблице.

Цены закупки

Страница «Цены закупки» показывает стоимость каждой партии деталей по методу FIFO в разрезе мест хранения.

Закупки и приход товара

Заказы поставщикам

В разделе «Заказы поставщикам» нажмите «Создать заказ», выберите поставщика и добавьте позиции с нужным количеством. Статус заказа изменяется кнопкой «Изменить статус». Когда товар поступил — нажмите «Оформить приход».

Документы прихода

В разделе «Приход товара» ведётся журнал всех поступлений. При создании прихода выберите деталь, место хранения, укажите количество и закупочную цену. После сохранения остатки на складе и цены закупки обновятся автоматически.

В карточке документа прихода кнопка «Лист размещения (PDF)» формирует документ для кладовщика с адресами мест хранения.

Запуск системы

Первый запуск Админ

Windows

Запустите файл autorun_Windows.bat двойным щелчком. Скрипт создаёт виртуальное окружение, устанавливает зависимости из папки packages/ без интернета, применяет миграции и открывает браузер по адресу http://127.0.0.1:8000. Для остановки закройте окно консоли.

Linux и macOS

В терминале перейдите в папку с проектом и выполните:

chmod +x autorun_Linux.sh
./autorun_Linux.sh

На Ubuntu/Debian при первом запуске может потребоваться: sudo apt install python3-venv

При первом запуске автоматически создаётся суперпользователь admin с паролем 12345. Смените пароль сразу после первого входа.

Панель администратора

Вход в панель администратора Админ

Панель администратора доступна по адресу http://127.0.0.1:8000/admin/. Для входа используйте учётную запись суперпользователя. Главная страница содержит разделы: «Пользователи», «Резервные копии», «Настройки системы» и «Лог действий».

Управление пользователями Админ

Активация учётной записи

Новый пользователь регистрируется самостоятельно. После регистрации учётная запись неактивна. Для активации откройте раздел «Пользователи», нажмите на имя нужного пользователя.

Установите флажок «Активен» и нажмите «Сохранить». Для деактивации снимите тот же флажок.

Назначение прав администратора

Чтобы предоставить пользователю права администратора, установите флажок «Статус персонала» на его странице и нажмите «Сохранить». Пользователь получит доступ к разделам «Настройки», «Персонал», «Администрирование» и к панели /admin/.

Настройки системы Админ

Раздел «Настройки системы» в панели администратора позволяет задать:

  • Часовой пояс — определяет временную зону для отображения всех дат. Изменение применяется немедленно без перезапуска.
  • Интервал автокопирования — количество дней между автоматическими резервными копиями (по умолчанию 7 дней).

После изменений нажмите «Сохранить».

Резервное копирование Админ

Резервные копии хранятся в папке backups/ в формате JSON и содержат все данные системы.

Создание копии

Система проверяет при каждом запросе, истёк ли настроенный интервал, и при необходимости создаёт копию автоматически. Для немедленного создания нажмите кнопку «Создать резервную копию» в разделе «Резервные копии» панели администратора.

Восстановление из копии

Способ 1 — через интерфейс системы: раздел «Администрирование» → «Импорт БД» → выберите файл резервной копии и нажмите «Импортировать».

Способ 2 — через терминал: активируйте виртуальное окружение и выполните команду:

python mykursovik2/manage.py loaddata backups/backup_YYYYMMDD_HHMMSS.json
Перед восстановлением создайте резервную копию текущего состояния — операция необратима.

Разделы для администратора

Настройки организации Админ

Раздел «Настройки» в группе «Склад» содержит реквизиты организации: наименование, форма собственности, ИНН, КПП, ОГРН, адрес, телефон, e-mail, стоимость нормо-часа и гарантийный срок. Эти данные используются при формировании PDF-документов.

Уже созданные заказы хранят снапшоты реквизитов на момент создания и не изменяются при обновлении настроек.

Сотрудники Админ

Раздел «Персонал» → «Сотрудники» содержит список сотрудников. Администратор добавляет сотрудников, указывает коэффициент заработной платы и при необходимости формирует отчёт о выполненных работах за период.

Экспорт и импорт базы данных Админ

Раздел «Администрирование» содержит инструменты переноса данных:

  • Экспорт БД — выгружает все данные в JSON-файл для переноса на другой компьютер.
  • Импорт БД — загружает ранее выгруженный файл, полностью заменяя текущие данные.
Импорт необратим — перед его выполнением обязательно создайте резервную копию.

Бухгалтерский экспорт Админ

Раздел «Бухгалтерия (Excel)» позволяет выгрузить данные о завершённых заказах, поступлениях и списаниях за выбранный период в файл Microsoft Excel. Укажите даты начала и конца периода и нажмите «Сформировать» — файл скачается автоматически.

Журнал действий Админ

Раздел «Лог действий» в панели администратора фиксирует все значимые операции: создание, изменение и удаление объектов. Для каждой записи указывается пользователь, время, тип действия и подробности изменений. Доступна фильтрация по типу действия, модели, пользователю и дате.

Записи журнала доступны только для просмотра — редактирование и удаление отключены.

Хранение данных Админ

Все данные системы хранятся в файле базы данных SQLite по пути db.sqlite3 в корневом каталоге проекта. Резервные копии в формате JSON хранятся в папке backups/. При переносе системы на новый компьютер достаточно скопировать весь каталог проекта целиком.
