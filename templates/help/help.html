Начало работы

Регистрация учётной записи

Система доступна в браузере по адресу http://127.0.0.1:8000. При первом обращении без авторизации вы автоматически перенаправляетесь на страницу входа. Для создания учётной записи нажмите ссылку «Зарегистрироваться».

Введите логин, пароль и подтверждение пароля, затем нажмите «Зарегистрироваться». После этого система отобразит страницу ожидания активации.

Самостоятельный вход до активации администратором невозможен.

Вход и выход из системы

Вход

После активации откройте http://127.0.0.1:8000, введите логин и пароль и нажмите «Войти». При неверных данных система выведет сообщение об ошибке.

Выход

Нажмите кнопку «Выйти» в нижней части бокового меню. Система завершит сеанс и вернёт вас на страницу входа.

Интерфейс системы

Интерфейс состоит из бокового меню навигации слева и основной рабочей области справа. Боковое меню содержит ссылки на все разделы: Заказы, Клиенты, Марки и модели, Услуги, Склад, Закупки. Активный раздел выделяется в меню.

Работа с клиентами

Клиенты и автомобили

Список клиентов

Нажмите «Клиенты» в боковом меню. Таблица показывает ФИО, номер телефона и количество привязанных автомобилей. Для поиска введите ФИО или телефон в строку поиска.

Добавление клиента

Нажмите «Добавить клиента». Заполните ФИО, код страны и номер телефона, отметьте согласие на обработку персональных данных. Система проверяет уникальность телефона при сохранении.

Карточка клиента

Нажмите на имя клиента — откроется его карточка с контактными данными и списком автомобилей. Для редактирования или удаления используйте соответствующие кнопки.

Добавление автомобиля

В карточке клиента нажмите «Добавить автомобиль». Выберите марку — список моделей обновится автоматически. Заполните государственный номер, VIN, цвет и год выпуска.

Система проверяет уникальность VIN и государственного номера — при дублировании форма не сохранится.

Работа с заказ-нарядами

Создание заказ-наряда

На главной странице нажмите «Добавить заказ». Начните вводить ФИО или телефон клиента — система покажет подходящие варианты. Выберите клиента, затем его автомобиль из подгруженного списка.

Укажите текущий пробег и при необходимости добавьте комментарий, затем нажмите «Сохранить».

Заказ создаётся со статусом «Первичный осмотр».

Создать заказ задним числом невозможно — дата не может быть в прошлом.

Карточка заказ-наряда

После создания заказа открывается его карточка. В верхней части — номер, дата, клиент, автомобиль, статус и итоговая стоимость. Ниже — блоки добавления услуг и деталей.

Добавление услуг

Нажмите «Добавить услугу». В открывшемся окне нажмите на нужную услугу — она переместится в правую часть. Скорректируйте нормо-часы и коэффициент сложности — цена пересчитается. Нажмите «Добавить выбранные».

Назначение исполнителя

Рядом с услугой нажмите кнопку назначения и выберите сотрудника из списка. Имя и коэффициент фиксируются в заказе.

Добавление запасных частей

Нажмите «Добавить деталь». Введите наименование или артикул — система покажет варианты из каталога с остатком на складе. Выберите деталь и укажите количество.

Изменение статуса

Заказ проходит статусы: Первичный осмотр → Диагностика → В работе → Готов. Допускается возврат к предыдущему статусу.

Завершение заказа

Завершение возможно только из статуса «Готов» при обязательно указанном способе оплаты. При завершении зарезервированные детали списываются со склада. Редактирование завершённого заказа невозможно.

Отмена заказа

Заказ можно отменить из любого активного статуса кнопкой «Отменить». Все зарезервированные детали автоматически возвращаются в свободный остаток.

Завершённые заказы удалить нельзя — это защита целостности истории.

Печать документов

В карточке заказа нажмите «Печать ▾» — раскроется меню с тремя пунктами:

  • Для механика — технический бланк с перечнем работ и деталей без стоимости; доступен только для незавершённых заказов.
  • Лист отборки — список деталей для комплектации со склада; отображается только при наличии деталей.
  • Заказ-наряд клиенту — для активных заказов предварительный документ, для статуса «Готов» или «Завершён» — финальный с итоговой стоимостью.

Справочники

Марки и модели автомобилей

Нажмите «Марки и модели» в меню. Выберите строку в таблице — активируются кнопки «Подробнее», «Изменить» и «Удалить».

Для просмотра и добавления моделей выберите марку и нажмите «Подробнее».

Удаление марки невозможно, если к ней привязаны автомобили клиентов.

Услуги

Нажмите «Услуги» в меню. Каталог услуг организован по типам. Выберите тип и нажмите «Подробнее» для просмотра и добавления услуг. При добавлении укажите название и базовое время в нормо-часах.

Базовое время используется по умолчанию при добавлении услуги в заказ — его можно изменить непосредственно в заказе.

Склад и закупки

Работа со складом

Номенклатура деталей

Раздел «Номенклатура» содержит список всех деталей с артикулами и названиями. Для добавления нажмите «Добавить деталь» и укажите артикул, название и при необходимости бренд.

Остатки на складе

Страница «Остатки» показывает все позиции: место хранения, общее количество, зарезервированный и доступный остаток, минимальный порог. При снижении остатка ниже минимума позиция выделяется.

Цены закупки

Страница «Цены закупки» показывает стоимость каждой партии деталей по методу FIFO в разрезе мест хранения.

Закупки и приход товара

Заказы поставщикам

В разделе «Заказы поставщикам» нажмите «Создать заказ», выберите поставщика и добавьте позиции с нужным количеством. Статус заказа изменяется кнопкой «Изменить статус». Когда товар поступил — нажмите «Оформить приход».

Приход товара

При создании прихода выберите деталь, место хранения, укажите количество и закупочную цену. После сохранения остатки и цены закупки обновятся автоматически.

Кнопка «Лист размещения (PDF)» формирует документ для кладовщика с адресами мест хранения.

Запуск системы

Первый запуск Админ

Windows

Запустите файл autorun_Windows.bat двойным щелчком. Скрипт создаёт виртуальное окружение, устанавливает зависимости из папки packages/ без интернета, применяет миграции и открывает браузер по адресу http://127.0.0.1:8000. Для остановки закройте окно консоли.

Linux и macOS

В терминале перейдите в папку с проектом и выполните:

chmod +x autorun_Linux.sh
./autorun_Linux.sh

На Ubuntu/Debian при первом запуске может потребоваться: sudo apt install python3-venv

При первом запуске автоматически создаётся суперпользователь admin с паролем 12345. Смените пароль сразу после первого входа.

Панель администратора

Вход в панель администратора Админ

Панель администратора доступна по адресу http://127.0.0.1:8000/admin/. Для входа используйте учётную запись суперпользователя. Главная страница содержит разделы: «Пользователи», «Резервные копии», «Настройки системы» и «Лог действий».

Смена пароля

При первом запуске создаётся учётная запись admin / 12345. Сменить пароль можно через меню в правом верхнем углу панели администратора.

Управление пользователями Админ

Активация учётной записи

Новый пользователь регистрируется самостоятельно, после чего учётная запись остаётся неактивной. Откройте раздел «Пользователи» и нажмите на имя нужного пользователя.

Установите флажок «Активен» и нажмите «Сохранить». Для деактивации снимите тот же флажок.

Назначение прав администратора

Установите флажок «Статус персонала» на странице пользователя и нажмите «Сохранить». Пользователь получит доступ к разделам «Настройки», «Персонал», «Администрирование» и к панели /admin/.

Настройки системы Админ

Раздел «Настройки системы» позволяет задать:

  • Часовой пояс — временная зона для отображения всех дат. Изменение применяется немедленно без перезапуска.
  • Интервал автокопирования — количество дней между автоматическими резервными копиями (по умолчанию 7 дней).

Резервное копирование Админ

Резервные копии хранятся в папке backups/ в формате JSON. Система автоматически создаёт копию при каждом HTTP-запросе, если истёк настроенный интервал.

Восстановление из копии

Способ 1 — через интерфейс: раздел «Администрирование» → «Импорт БД» → выберите файл и нажмите «Импортировать».

Способ 2 — через терминал:

python mykursovik2/manage.py loaddata backups/backup_YYYYMMDD_HHMMSS.json
Перед восстановлением создайте резервную копию текущего состояния — операция необратима.

Разделы для администратора

Настройки организации Админ

Раздел «Настройки» (группа «Склад») содержит реквизиты организации: наименование, ИНН, КПП, ОГРН, адрес, телефон, e-mail, стоимость нормо-часа и гарантийный срок. Эти данные используются при формировании PDF-документов.

Уже созданные заказы хранят снапшоты реквизитов на момент создания и не изменяются при обновлении настроек.

Экспорт, импорт и бухгалтерия Админ

  • Экспорт БД — выгружает все данные в JSON-файл для переноса на другой компьютер.
  • Импорт БД — загружает ранее выгруженный файл, полностью заменяя текущие данные.
  • Бухгалтерия (Excel) — выгружает данные о завершённых заказах, поступлениях и списаниях за указанный период в файл Microsoft Excel.
Импорт необратим — перед его выполнением обязательно создайте резервную копию.

Журнал действий Админ

Раздел «Лог действий» фиксирует все операции: создание, изменение и удаление объектов. Для каждой записи указывается пользователь, время, тип действия, IP-адрес и подробности. Доступна фильтрация по типу действия, модели, пользователю и дате.

Записи журнала доступны только для просмотра — редактирование и удаление отключены.

Хранение данных Админ

Все данные системы хранятся в файле db.sqlite3 в корневом каталоге проекта. Резервные копии хранятся в папке backups/. При переносе системы на новый компьютер достаточно скопировать весь каталог проекта целиком.
